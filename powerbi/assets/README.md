`CY24SU10.json` is Power BI's standard "CY24SU10" base theme, as written by Power BI Desktop into
every PBIR report. This copy comes from a Desktop export in
[alisonpezzott/pbi_file_formats](https://github.com/alisonpezzott/pbi_file_formats) (MIT licence).
`build_pbip.py` copies it into the report's `StaticResources/SharedResources/BaseThemes/` folder.
