# AI-written SQL: verification log

Not run yet. This file is generated by:

```
set GEMINI_API_KEY=...        (PowerShell: $env:GEMINI_API_KEY="...")
set GEMINI_MODEL=...
python -m evaluation.sql_eval --gemini
```

It gives each of the 10 questions in `evaluation/questions.json` to Gemini with the schema
description only, runs the AI's SQL on a read-only database, compares the result with a verified
query, and records the outcome. Where the AI is wrong, the verified query is shown as the
correction. Afterwards, fill in **What I checked** under each question.
